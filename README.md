PictureJumper is a platformer I made in godot that utilizes the [random word api](https://random-word-api.herokuapp.com/home) so if you type the word on screen correctly, you get a little jumpboost, and it also uses [picsum.photos](picsum.photos) to grab images that act as a background. Otherwise, this plays like a standard climbing platformer. To play it, all you need to do is click on the itch.io link (https://kanokid.itch.io/picturejumper), it auto loads and you use Space and W for jump, A and Left for moving left, and D and Right for moving right.
